# 📌 Project Overview

The **Mobile Sales Dashboard** is a Business Intelligence project developed using **Power BI** to transform raw mobile sales data into meaningful business insights. The dashboard provides an interactive interface for analyzing sales performance, customer behavior, product demand, and regional trends.

Users can filter and explore data dynamically using slicers and interactive visuals, making it easier to identify sales opportunities and support strategic decision-making.

---

# 🎯 Purpose

The main objectives of this project are to:

- Analyze overall mobile sales performance.
- Monitor revenue, quantity sold, and transaction volume.
- Compare sales across brands and mobile models.
- Track monthly and yearly sales trends.
- Identify top-performing cities and regions.
- Analyze customer payment methods and ratings.
- Build an interactive dashboard for business decision-making.

# 📂 Data Source

The dashboard is built using a sample **Mobile Sales Dataset** containing transactional sales records.

### Dataset includes:

- Mobile Brand
- Mobile Model
- Sales Date
- Customer Name
- City
- Quantity Sold
- Unit Price
- Total Sales
- Payment Method
- Customer Rating

> **Note:** The dataset is used for educational and portfolio purposes.
